## Building the fully Open Source Platform for AI, for Everyone

LibreChat started as a unified interface for AI models and has grown into a broader open-source ecosystem for building, deploying, and extending AI applications.

The organization contains the core platform, agent infrastructure, retrieval systems, secure code execution, developer tooling, MCP integrations, and the services that power the LibreChat experience.

## Why LibreChat?

**Own your infrastructure.**  
Run locally, on your own servers, or in the cloud.

**Use the models you want.**  
Connect commercial APIs, open models, local inference, or custom endpoints.

**Build beyond chat.**  
Create agents, connect tools through MCP, execute code, retrieve knowledge, and build complete AI workflows.

**Stay open.**  
LibreChat is developed publicly and designed around extensibility rather than vendor lock-in.
